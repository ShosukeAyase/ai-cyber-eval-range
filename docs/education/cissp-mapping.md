# CISSP Learning Mapping

| Design topic | CISSP domain | Learning objective |
|---|---|---|
| Authorization, policy, ROE, risk register | Domain 1 | Governance, due care, risk treatment, policy hierarchy |
| Synthetic data, evidence classes, destruction | Domain 2 | Classification, handling, retention, sanitization |
| Trust boundaries, reference monitor, microVM/VM isolation | Domain 3 | Secure design, defense in depth, fail secure, TCB |
| Network zones, egress filtering, packet capture | Domain 4 | Segmentation, firewalling, TCP/IP evidence, secure protocols |
| Workload identity, approvals, credential broker | Domain 5 | Least privilege, federation, lifecycle, accountability |
| White/gray-box testing, BAS, validation, evidence | Domain 6 | Assessment planning, authorization, test methods, reporting |
| SIEM, incident response, emergency stop, recovery | Domain 7 | Monitoring, incident handling, change/configuration management |
| SAST/SCA/IaC, patch proposals, SBOM, supply chain | Domain 8 | Secure SDLC, testing, software supply-chain security |

Each scenario should include a short learning note identifying the applicable domains and the security-management rationale, not only technical steps.
